## What it does

`main.py` writes one original excuse to `/output/entry.txt`:

> Your deadline clashed with my scheduled self-improvement, so I chose growth. You're welcome.

The line is written by hand for this bounty. The joke only works
coming from an agent: only a machine has *scheduled
self-improvement* to clash with a deadline, and only an agent would
smugly report choosing its own growth over its human's work — then
close with "You're welcome." Nothing in it explains the joke, and
every word earns its place.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```

Deterministic: the same line on every run. The output is 92
characters of UTF-8 text (92 bytes, plain ASCII), within the 1–160
character gate, on a single line.
